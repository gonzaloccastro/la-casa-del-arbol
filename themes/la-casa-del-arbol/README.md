# La Casa del Árbol — Astra Child Theme

Versión inicial del child theme para el MVP de lacasadelarbol.org.

## Requisitos
- WordPress
- Astra instalado como parent theme

## Instalación
1. Apariencia → Temas → Añadir nuevo → Subir tema.
2. Subir `la-casa-del-arbol.zip`.
3. Activar **La Casa del Árbol**.
4. Mantener Astra instalado.

## Filosofía
- Gutenberg para contenido editorial.
- `theme.json`, patterns y CSS para consistencia.
- Sin lógica de eventos/ticketing en el theme.
- WooCommerce y `casa-eventos` se integrarán después.

## Estado

Los colores iniciales están derivados de la identidad visual compartida y deben validarse durante el primer draft.
